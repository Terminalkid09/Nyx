# Wordlist attribution

Bundled lists are unmodified copies of files from
[SecLists](https://github.com/danielmiessler/SecLists) (MIT License,
Copyright (c) 2017 Daniel Miessler):

| Local file | SecLists path |
|---|---|
| `directories.txt` | `Discovery/Web-Content/raft-small-directories.txt` |
| `files.txt` | `Discovery/Web-Content/raft-small-files.txt` |
| `common.txt` | `Discovery/Web-Content/common.txt` |
| `params.txt` | `Discovery/Web-Content/burp-parameter-names.txt` |
| `api.txt` | `Discovery/Web-Content/api/api-endpoints.txt` |

`content_discovery.txt` (quick default for the scan pipeline) and
`backups.txt` are curated by the Nyx maintainers.

Imported lists are stored next to these files and are user-provided; they are
not covered by the attribution above.
