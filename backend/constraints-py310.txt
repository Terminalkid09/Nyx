# mitmproxy 11.0.2 (Dec 2024) pins typing-extensions<=4.11.0 on Python <3.11.

# to find a compatible set. Pinning the era-consistent versions makes fresh
# installs resolve in seconds.
#
# Usage:
#   pip install -r requirements.txt -r requirements-dev.txt -c constraints-py310.txt
